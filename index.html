Questions

Asked often

Does my code leave my machine?

Kage runs your own Claude Code session on your laptop, like any Claude Code session. It opens an outbound connection to Slack, so it needs no public URL and no open port. Your files and tools stay on your machine.

Who can drive it?

Only you. Kage acts only on messages you typed yourself, and drops everyone else before Claude sees anything. A teammate you add can tag it only in conversations you are in. Anything that needs your yes waits for you, and a teammate can never approve a prompt.

What do I need?

macOS or Linux, Node 22.18 or newer, tmux, and a recent Claude Code logged in with a claude.ai account. You also need permission to create an app in your Slack workspace.

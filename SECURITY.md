# Security

Kage runs Claude Code on your machine with your files and tokens, so a bug in who may reach it matters.

Report a vulnerability privately through [GitHub security advisories](https://github.com/aloki-alok/kage/security/advisories/new). Please do not open a public issue for it.

You get a first answer within 3 days. A fix for a confirmed issue ships as a patch release with a note in the release.
